# H36 Invisible Editor — v29 experimental inspector

- Existing v28 Data World layout, 124 nodes, 349 edges, Orbit/Explore, clouds, filters, language controls are preserved.
- Clicking a node adds an inspector distinguishing **Evidence / Inference / Interpretation**.
- Evidence records are a **minimal public subset** of v28 provenance audit. The audit marks legacy cases as unverified. No research catalog or private audit file is shipped.
- The inspector shows mechanism tags, existing edge types and their epistemic limits. It does not claim that classification decisions have been independently verified.
- H36 is an audit/display experiment, **not** a new validated information representation method.
- Later research: per-tag/edge source evidence, alternative editorial decisions, comparison tasks and 2D/v28/v29 evaluations.
- JS syntax and static structural checks run; full browser regression testing is still required.
